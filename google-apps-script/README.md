# Spreadsheet上書き用Apps Script

1. Google Apps Scriptで新しいプロジェクトを作成し、`Code.gs`の内容を貼り付けます。
2. プロジェクトの設定 > スクリプト プロパティに `QRTOQR_TOKEN` を追加し、推測されにくい長い文字列を値にします。
3. 「デプロイ」>「新しいデプロイ」>「ウェブアプリ」を選択します。
4. 実行ユーザーを「自分」、アクセスできるユーザーを「全員」にしてデプロイします。
5. 発行された `/exec` URLと、手順2のトークンをQRtoQRのエクスポート画面に入力します。

WebアプリURLと共有トークンは、同じブラウザのローカルストレージに保存されます。トークンは第三者に公開しないでください。
